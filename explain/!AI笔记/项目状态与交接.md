## 4. 环境坑(每个都真踩过)

| 坑 | 结论 |
|---|---|
| `git push` 报 `could not read Username` + `sh.exe: couldn't create signal pipe, Win32 error 5` | 沙箱禁命名管道,把 Git Credential Manager 挡在外面。需要更宽的沙箱权限 |
| 只读沙箱下 `cl` 报 `D8050 无法执行 c1xx.dll` | 构建需要 workspace-write |
| 路径里有 `[Mira]` 这种方括号 | PowerShell 的 `Get-Content`/`Select-String` 会当**通配符** ⇒ 必须 `-LiteralPath`;`rg` 也踩 |
| `$env:TEMP` | **每次调用都是不同的沙箱目录** ⇒ 临时文件用固定绝对路径 |
| Typora | 会把文件**截成 0 字节**(恢复:`%APPDATA%\Typora\draftsRecover\`) |
| 编辑器占用 | 用户在 VS2022 里开着旧 buffer 时保存会**覆盖磁盘**(发生过两次)⇒ 改完提醒「文件 → 重新加载」 |
| **★ 行尾 CRLF 被写坏(2026-09-30,我自己干的)** | 我对 CRLF 文件做了 `整串 \n → \r\n` 替换 ⇒ 每个 `\r\n` 变成 `\r\r\n`,调两次还叠加成 `\r\r\r\n`,RAD 手册**整文件 1282 行假 diff**。修复:`[regex]::Replace($t,"\r{2,}\n","`r`n")`。**规矩:改行尾只能"原样字节回写"或只做行级替换**,并且先 `([regex]::Matches($t,"\r{2,}")).Count` 自检 |
| **MSBuild:ItemDefinitionGroup 漏 Condition** | 两组配置会**同时作用于所有配置** ⇒ Debug 拿到 `/O2` 撞 `/RTC1`(`error D8016`)。Debug/Release 两组都必须写 `Condition` |
| **MSBuild:`LinkIncremental` 放 `<Link>` 里无效** | 必须写在**配置级 PropertyGroup**(与 `PlatformToolset`/`CharacterSet` 同级),否则 `LNK4075` |
| 批量改文档脚本的守卫 | 锚点必须"当时唯一";守卫用"模式必须恰好命中 1 行,否则 `throw`,`写盘放最后`" ⇒ 撞了就零副作用 |

## 5. 构建参数的陷阱(`-W4 -WX`:警告即错误)

**抑制列表**(现在写在 `HandMade.vcxproj` 里,别擅自扩大):
`4201 4100 4505 4189 4457 4456 4819`

| 警告 | 什么情况 | 在抑制列表里吗 |
|---|---|---|
| **C4244** | `uint32 x = WParam;`(x64 下 WPARAM 64 位) | ❌ **直接编不过** ⇒ 写 `(uint32)WParam` |
| **C2446 / C4130** | `VKCode == "W"` | ❌ ⇒ 用**单引号** `'W'` |
| **C4554** | `a & b != 0` 优先级可疑 | ❌ ⇒ 位运算与比较混用必须加括号 |
| C4800 | `bool x = 某位运算;` | ❌(只在开优化时出现) |
| C4189 | "局部变量定义了没用" | ✅ 被吞 ⇒ **编译器不会替你抓死变量** |
| **C4456** | 局部变量**遮蔽**外层同名变量 | ✅ 被吞 ⇒ 2026-09-24 那个"分层加载"bug 就是这么溜过去的 |

> 📌 教训:每条 `-wd` 都可能是"真 bug 的静音开关"。**改抑制列表是用户的决定**(`NOTES.md` §6.4)。
> 📌 另有 **`/permissive-`**(工程开着,比 Casey 参数**更严**):哪天它报了 cl 不报的错,那是严格度差异。
