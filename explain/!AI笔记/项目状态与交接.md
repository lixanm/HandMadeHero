## 4. 环境坑(每个都真踩过)

| 坑 | 结论 |
|---|---|
| `git push` 报 `could not read Username` + `sh.exe: couldn't create signal pipe, Win32 error 5` | **沙箱禁命名管道**,把 Git Credential Manager 挡在外面(凭据本身是好的)。需要**更宽的沙箱权限**才能推 |
| 只读沙箱下 `cl` 报 `D8050 无法执行 c1xx.dll` | 构建需要 workspace-write |
| 路径里有 `[Mira]` 这种方括号 | PowerShell 的 `Get-Content`/`Select-String` 会当**通配符** ⇒ 必须 **`-LiteralPath`**;`rg` 也会踩 |
| `$env:TEMP` | **每次调用都是不同的沙箱目录** ⇒ 临时文件一律用固定绝对路径 |
| Typora | 会把文件**截成 0 字节**(恢复:`%APPDATA%\Typora\draftsRecover\`)⇒ 改文档前后都要看 `LastWriteTime`/`Length` |
| 编辑器占用 | 用户在 Emacs/Typora 里开着旧 buffer 时保存会**覆盖磁盘**(发生过两次)⇒ 改完提醒 `revert-buffer` |

## 5. 构建参数的陷阱(`-W4 -WX`:警告即错误)

**抑制列表**(`build.bat` 里已有的,别擅自扩大):
`-wd4201 -wd4100 -wd4505 -wd4189 -wd4457 -wd4456 -wd4819`

| 警告 | 什么情况 | 在抑制列表里吗 |
|---|---|---|
| **C4244** | `uint32 x = WParam;`(x64 下 WPARAM 是 64 位) | ❌ **会直接编不过** ⇒ 要写 `(uint32)WParam` |
| **C2446 / C4130** | `VKCode == "W"`(字符串字面量不是字符) | ❌ ⇒ 用**单引号** `'W'` |
| **C4554** | `a & b != 0` 这种优先级可疑(缺括号) | ❌ ⇒ **位运算和比较混用必须加括号** |
| C4800 | `bool x = 某位运算;`(强制 0/1 的性能警告) | ❌(只在开优化时出现) |
| C4189 | "局部变量定义了没用" | ✅ 被 `-wd4189` 吞了 ⇒ **编译器不会替你抓死变量** |
