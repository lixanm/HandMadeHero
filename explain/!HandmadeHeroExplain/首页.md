## 📋 这册里的约定

- **证据等级**(沿用仓库根 `NOTES.md` §2.2):引用都带**视频时间戳**;字幕是 ASR,API 名和数字常有错,
  凡 **API 签名、常量值**都在本机 SDK 头文件里核实过,出处写在每篇的「附录 D:本文档的事实核对来源」。
- **🟡 = 我的推断**,不是 Casey 的原话;凡是标了 🟡 的地方都可以怀疑。
- **`★` = 该篇的重点章节**(标题里带 `★` 的);
  **`📍` = "对我们的意义"**(我们的代码/我们的类银河城该怎么用);
  **`⚠️` = 容易踩的坑**;**`📌` = 补充说明**;**`⭐` = 一句话结论**。
- 时间戳形如 `01:04:06`,对应 `explain\!subtitle\[Mira] Handmade Hero Day 00X - ….txt`(每篇属性里有路径)。
