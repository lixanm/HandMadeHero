## 二、代码:今天改了三轮

### 1. 早上:让窗口能正常关闭 ✅

**背景**:09-18 留下的问题 —— 点 X 关不掉窗口(`WM_CLOSE` 的 case 只打印一行就 `break`,把"销毁窗口"这件默认处理的活拦下来了)。

**做法**:引入 `Running` 全局标志,消息循环改成 `while (Running)`,`WM_CLOSE` / `WM_DESTROY` 里把它设成 `false`。

**实测**:给窗口发 `WM_CLOSE` → **进程正常退出,`ExitCode = 0`** ✅

### 2. 中午:按 Day 3 实现后备缓冲 ✅

新增了一整段「后备缓冲」,原来的 `PatBlt` 黑白闪烁被取代:

| 加的 | 作用 |
|---|---|
| `BitmapInfo` / `BitmapMemory` / `BitmapWidth` / `BitmapHeight` | 位图的"说明书"、像素内存、尺寸 |
| `Win32ResizeDIBSection(Width, Height)` | 按客户区尺寸(重新)创建后备缓冲 |
| `Win32UpdateWindow(HDC, X, Y, W, H)` | 用 `StretchDIBits` 把缓冲贴到窗口 |
| `WM_SIZE` / `WM_PAINT` 接线 | 尺寸变了就重建;该重画就贴图 |

**实测(截屏取色)**:程序运行时屏幕主色是 **RGB(153,102,51) 占 86.9%** —— 正是我们写进内存的那个值;程序退出后这个颜色完全消失。**证明"写内存 → blit → 屏幕"这条链是通的。**

### 3. 晚上:按 Day 4 的更正删掉多余机制 ✅

Day 4 明确纠正:"用 `StretchDIBits`(它直接收像素指针),就**不需要 DC、也不需要位图句柄**"。

**删掉的东西**:

| 删掉 | 替代 |
|---|---|
| `global_variable HBITMAP BitmapHandle;` | 不需要 |
| `global_variable HDC BitmapDeviceContext;` | 不需要 |
| `DeleteObject(BitmapHandle);` | → `VirtualFree(BitmapMemory, 0, MEM_RELEASE)` |
| `CreateCompatibleDC(0)` | 整段删除 |
| `CreateDIBSection(...)` | → **`VirtualAlloc(0, 宽×高×4, MEM_COMMIT, PAGE_READWRITE)`** |

**保留**:`BitmapInfo`(还需要 —— `StretchDIBits` 靠它知道格式)、`BitmapMemory`、两个尺寸、`Win32UpdateWindow`、`WM_PAINT`,以及**那段临时纯色**(故意留着 —— 只删不补的话窗口会变全黑,没法判断改动是否成功)。

**实测**:`build.bat`(`-W4 -WX`)通过;运行后窗口区域 **87.9% 仍是 RGB(153,102,51)**,中心像素正是这个值 ✅ —— 说明**自己分配内存这条路是对的,DC 和位图句柄确实是多余的**。

### 4. 顺带:给代码加了简略注释

文件头失效路径修正、`case` 为什么必须用 `{}` 包住、`WM_CLOSE` 的坑、消息循环的返回值含义、`WinMain` 四个参数、两处 `//todo` 展开成 `TODO: 记日志(GetLastError)`。(只加注释、逻辑一行没动 —— 用"去掉所有注释后逐行对比"验证过。)

## 六、今天搞懂的概念(挑几个关键的)

| 概念 | 一句话 |
|---|---|
| **位图** | 就是"每个点什么颜色"的一块内存,不是文件、不是高级对象 |
| **blit** | 把一整块像素从 A 复制到 B;`StretchDIBits` 还能缩放 |
| **后备缓冲 / 双缓冲** | 先在看不见的图上画好,再一次性换给用户看 —— 否则会闪 |
| **DC** | "作画工具包";但我们用 `StretchDIBits` 后**连它都不需要了** |
| **`VirtualAlloc`** | 直接向系统按页(4096 字节)要内存;`MEM_COMMIT` 才是真的给你 |
| **`biHeight` 正负** | 正数 = 自下而上(内存第一行是画面最下面),负数 = 自上而下 |
| **BGR 顺序** | Windows 位图内存里是"蓝绿红 pad";因为小端机器上那样读进寄存器才显示成 R,G,B |
| **`.lib` vs `.dll`** | 链接时的介绍信 / 运行时真正装代码的文件 |
| **`D:` 是什么** | 是 `subst` 映射:`D:\` → `C:\THOTH\DaiMaXuNiJi\NEWCODE`,所以 `D:\HandMade` 和 `C:\THOTH\...\HandMade` 是同一批文件 |

**工具类的问题也问了几个**(不影响代码,记一笔):VS2022 的 TODO 怎么在右侧缩略图看到(原生没有 TODO 批注,只能用任务列表 + 书签)、单文件怎么左右分屏(`Window → 新建窗口` + 垂直选项卡组)、水平滚动条不见了(多半是"自动换行"开着)。
