## 什么时候该写一条

满足**任意一条**就写:

1. 这个选择**以后很难改**(单向门);
2. 它会影响**很多文件 / 很多集**;
3. 将来一定会有人问"当初为什么这么做" —— 包括半年后的你自己。

## 模板

```markdown
# NNNN — 一句话说清这个决定

- **状态**:提议 / 已采纳 / 已废弃(被 NNNN 取代)
- **日期**:YYYY-MM-DD
- **相关**:涉及的文件、日志、其它 ADR

## 背景
为什么会面临这个选择?当时的约束是什么?

## 决定
我们到底选了什么(写成可执行、可检查的表述)。

## 后果
### 好的
### 代价 / 需要盯着的

## 考虑过的替代方案
| 方案 | 为什么不选 |
|---|---|
```
