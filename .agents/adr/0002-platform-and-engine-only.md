# 0002 — 只跟平台层与引擎层,游戏做类银河城

- **状态**:已采纳
- **日期**:2026-09-24
- **相关**:`README.md`(开头那段"跟什么、不跟什么")、`explain\HANDMADE_HERO_终点与导航.md`

## 背景

Handmade Hero 是一部 ~~600 多集的系列:它前半段在写**平台层与引擎层**(与游戏类型无关),
后半段在做**他自己的那款游戏**:一个地牢探索类游戏(程序化房间 + 2.5D 投影 + 光照 + Brains)。

跟着学的时候很容易不自觉地"照抄整条路线",于是最后做出来的会**不是自己想做的游戏**,
而且会以为"教程的终点 = 我的终点"。

## 决定

1. **平台层与引擎层跟着学**:窗口 / 输入 / 音频 / 文件 / 线程 / 计时 / 资产加载 / 内存,
   以及渲染器、音频、资产管线、工具 —— 这些**与游戏类型无关**,照做;
2. **游戏层自己做**:玩法、关卡与地图结构、能力解锁与回溯、存档点、Boss —— 按**类银河城(Metroidvania)**设计;
3. **判断标准**:一个模块如果"换成任何类型的游戏都还成立",就属于引擎层,可以跟;
   如果它回答的是"这个游戏怎么玩",就属于游戏层,必须自己长出来。

## 后果

**好的**

- 学的是**可迁移**的东西;平台层的代码换到任何项目都能用;
- 不会被教程的终点绑住 —— 教程做地牢,我们做类银河城;
- 面对"这一段要不要照抄"时有一个**可判断**的准则,而不是凭感觉。

**代价 / 需要盯着的**

- 每一集都要多问一句"这一集的内容属于哪一层"(成本很低,收益很高);
- 参考他的**时间线**容易变成"以他的进度为我的进度" —— 所以 `Day N` 一律解释为
  "我跟视频学到第 N 集",**不是**我们游戏的进度条(见 `GLOSSARY.md`);
- 他的后半段内容(游戏层)对我们只有**旁证**价值,不能当实现指南。

## 考虑过的替代方案

| 方案 | 为什么不选 |
|---|---|
| 完整复刻他的游戏(地牢探索) | 那不是用户想做的游戏;做完也不是自己的作品 |
| 完全脱离教程,自己写平台层 | 平台层是"行业公物",重造只会烧光时间,类银河城永远做不出来 |
| 只用引擎(Unity/Unreal),把精力全放玩法 | 与"不用任何框架、自己写引擎"的项目目的直接冲突 |
