# 调试循环

**核心:先让 bug 变得可观察,再动手改代码。**

"我猜是 X,改成 Y,好像好了" —— 那不是调试,是碰运气:不可重复,也无法证明修好了。

## 本机工具(先看这里,别重新发明)

| 要干什么 | 用什么 | 备注 |
|---|---|---|
| 快反馈 | `HandMade\build.bat`(或 VS 里 F7) | `/W4 /WX`:警告即失败 —— 这是**免费**的一轮检查 |
| 看程序自己打的字 | `cdb -g -G <exe>` 捕获 `OutputDebugStringA` | 初始化里有 6 处诊断输出 |
| 看真实反汇编 | `dumpbin /disasm <exe>` | 例:验证 `call qword ptr [rax+30h]` 是不是第 6 格 |
| 看依赖 / 导出 / 导入 | `dumpbin /dependents` `/exports` `/imports` | 例:证明 `/MT` 静态 CRT 生效(只依赖 3 个系统 DLL) |
| 造"真实"输入 | `keybd_event`(先确认 `GetForegroundWindow()==hwnd`);`PostMessage` 造精确 `LPARAM` 位 | `PostMessage` 只能测消息处理,**测不了**键盘状态机 |
| 图形化调试 | `debug.bat`(RAD Debugger;**必须 `raddbg.exe`**) | 断点、看内存、看 `WAVEFORMATEX` 这类结构体 |
| 宏展开 / 汇编列表 | `cl -E` / `cl -Fa` | `-Fa` 区分大小写(`/FA` 不是同一个开关) |
| 源码关系 | Sourcetrail(`HandMade.srctrlprj`) | 只读;它不认 MSVC 参数,走 `compile_commands.json` |

## 循环:七步,每步都有完成条件

1. **造红回路** —— 一条命令或一次操作,能**稳定**复现这个 bug,且**好**的时候稳定变绿。
   完成条件:你能说出"跑这个 → 这样;改那个 → 那样"。
   **没有红回路就不许改代码** —— 否则无法区分"修好了"和"这次碰巧没出现"。
2. **最小化** —— 把复现范围缩到最小(去掉无关的键、无关的输入、无关的帧)。
   完成条件:复现步骤能写在**三行以内**。
3. **写一条假设** —— 每次只写一条,而且要可证伪:"如果 X 成立,插桩后 Y 会变"。
   ❌ "大概是缓冲区的问题" 不是假设,是心情。
4. **插桩** —— `OutputDebugStringA` / 断点 / 打印数值,去**看**。
   完成条件:拿到实测数据(不是"感觉像是")。
5. **改最小的一处**。
6. **回归** —— 用第 1 步的回路再跑:**必须变绿**;同时**原来正常的功能还要正常**
   (例:改 `WAVEFORMATEX` 字段顺序,别把缓冲大小一起搞坏)。
   完成条件:回路绿 **且** 编译零警告。
7. **记录** —— 写进当天日志:`我以为 → 实际 → 差距`(照 `explain\2026-9\` 的既有格式)。

## 这个项目的已知陷阱(别重复踩)

- **字幕是 ASR**:API 名与数字常错 ⇒ 结论必须回到 SDK 头文件核实(`NOTES.md` §2.2);
- **`HRESULT` 与 Win32 错误码是两个命名空间**:`SUCCEEDED(1167)` 为**真** ⇒ 判失败要用对宏;
- **"把结构体清零"会掩盖漏赋值**:清零之后编译器不再警告"用了未初始化的成员";
- **`-wd4456` / `-wd4189` 是关掉的**:同名遮蔽、定义了没用到 —— 编译器**不会**提醒你;
- **改文件前先问"它有没有正在编辑器里开着"**(`NOTES.md` §1.5);
- **不许只凭回忆说"我改过了"**:代码看 `git diff`,文档看 `LastWriteTime` + `Length`。

## 整轮的完成条件

一次调试算完成,当且仅当:**红回路变绿** 且 **有可回查的证据(命令 + 输出)写进了日志**。
两者缺一 = 没完成。
